# OSKAR
Open Source Kombat Arena Radio
A mesh radio system that will allow several devices to communicate robustly whilst moving around an outdoor arena. The specific case use is a LASER-tag game so that score data from all participants is up-to-date and accurate. With a minimum of two devices, the system will simply work as two-way communication. As more devices are added; either mobile or static for example with a ‘capture the flag type game’ the network will strengthen and could cover a larger area.
By creating this project as open-source it will allow people to build their own compatible system, free of licensing costs and the limitations of closed systems. Makers of the system will easily be able to join with others who have used this same design.
